# 🐱 FeederKu — Smart IoT Cat Feeder

Website promosi & e-commerce untuk **FeederKu Pro**, alat pemberi makan kucing otomatis berbasis **IoT** yang bisa dikontrol langsung dari smartphone.

![FeederKu Banner](https://images.unsplash.com/photo-1519052537078-e6302a4968d4?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Fitur Utama

- 🎨 **Desain ceria & playful** — warna mango, bubblegum, mint, deepsea
- 📱 **Fully responsive** — tampil cantik di mobile, tablet & desktop
- 🌊 **Animasi hidup** — float, wiggle, blob, marquee, fadeIn
- 🛒 **Halaman checkout lengkap** — dengan validasi real-time
- 🏦 **Pilihan bank dengan logo** — BCA, BNI, Mandiri, BRI, Bank Lain
- 💬 **Order via WhatsApp** — pesanan otomatis terkirim ke admin
- 🗺️ **Google Maps lokasi workshop** — Porong, Sidoarjo
- ⬇️ **Download aplikasi** — langsung dari Google Drive

## 🛠️ Tech Stack

- ⚛️ **React 18** — UI library
- ⚡ **Vite** — build tool super cepat
- 🎨 **Tailwind CSS 3** — utility-first styling
- 📱 **State-based routing** — tanpa react-router (ringan)
- 🖼️ **Google Fonts** — Baloo 2 + Nunito
- 🗺️ **Google Maps Embed** — lokasi workshop
